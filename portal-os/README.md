# Portal-OS - Runtime Engine

Portal-OS is the operating system generated by SIM. It provides a complete runtime with kernel, services, web shell, APIs, and modular applications (suites).

## Structure

- **kernel/**: Scheduler, memory, IPC, drivers
- **runtime/**: Bootstrap, routing, services
- **shell/**: Web server and UI
- **api/**: Public and internal endpoints
- **suites/**: Modular applications

## Purpose

Portal-OS transforms SIM's compiled specifications into a running operating system. It manages resources, routes requests, serves the user interface, and coordinates all applications and services.
