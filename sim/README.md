# SIM - Builder Engine

SIM is the cognitive and compilation engine that generates Portal-OS configurations and orchestrates execution.

## Structure

- **mode/**: Cognitive primitives and operators
- **code/**: Compiler and execution scheduling
- **pipeline/**: Workflow orchestration
- **config/**: Environment profiles and settings

## Purpose

SIM takes high-level specifications and compiles them into executable Portal-OS runtime configurations. It includes the cognitive primitives (MODE), execution logic (CODE), workflow orchestration (PIPELINE), and environment management (CONFIG).
