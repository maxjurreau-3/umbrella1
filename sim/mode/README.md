# MODE - Cognitive Primitives

MODE defines the fundamental data types, states, transforms, and operators used throughout the Umbrella Ecosystem.

## Subdirectories

- **primitives/**: Core data types (vectors, states, transforms)
- **operators/**: Transformations and operations
- **cognitive_graphs/**: Graph structures for cognitive reasoning

## Role in SIM

MODE is the foundation layer. All other SIM components (CODE, PIPELINE) and Portal-OS services depend on MODE primitives.
