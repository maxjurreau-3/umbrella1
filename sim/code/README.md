# CODE - Compiler & Execution

CODE contains the compilation logic, task schedulers, and I/O handlers that transform MODE definitions into executable code and Portal-OS commands.

## Subdirectories

- **compiler/**: Compilation logic
- **schedulers/**: Task scheduling and resource allocation
- **io/**: Input/output handling

## Role in SIM

CODE takes MODE primitives and uses them to compile Portal-OS configurations. It schedules execution of workflows and manages I/O operations.
