# Infra - Deployment & Operations

Infra provides development, deployment, CI/CD, and monitoring infrastructure.

## Structure

- **dev_server/**: Local development server
- **deployment/**: Production deployment scripts
- **ci_cd/**: Continuous integration and deployment
- **monitoring/**: Observability and alerting

## Purpose

Infra supports the entire Umbrella Ecosystem through development tooling, deployment automation, testing, and production monitoring.
