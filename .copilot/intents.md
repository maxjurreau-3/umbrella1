# Copilot Intents — Umbrella Ecosystem

This repository defines a multi-layer operating system called **Portal-OS**, generated by a cognitive engine called **SIM** and deployed inside the **Umbrella Ecosystem**.

Copilot should generate code that aligns with the following intents:

---

## 1. SIM (Builder Engine)

SIM is the cognitive and compilation engine that generates Portal-OS and orchestrates substrate operations.

### Components:

- **MODE**: Cognitive primitives, operators, and graph logic
  - Vectors, states, transforms
  - Math and logic operators
  - Cognitive graph structures
  
- **CODE**: Compiler, schedulers, IO
  - Compilation logic
  - Task scheduling
  - Input/output handling
  
- **PIPELINE**: Deterministic multi-stage workflows
  - Workflow graphs
  - Stage definitions
  - Pipeline orchestration
  
- **CONFIG**: Profiles and environment definitions
  - Environment profiles
  - Configuration loaders
  - Runtime settings

### Copilot should generate:
- Primitive definitions (vectors, states, transforms)
- Operators (math, logic, graph transforms)
- Compiler scaffolding and implementations
- Pipeline orchestrators
- Config loaders and parsers

---

## 2. Portal-OS (Runtime Engine)

Portal-OS is the operating system SIM produces. It runs on the Substrate and coordinates all runtime services and applications.

### Components:

- **KERNEL**: Scheduler, memory, IPC, drivers
  - Task scheduler
  - Memory management
  - Inter-process communication
  - Device drivers
  
- **RUNTIME**: Bootstrap, routing, services
  - Bootstrap sequence
  - Request routing
  - Service registry and management
  
- **SHELL**: Web UI, components, assets
  - Web server
  - UI component library
  - Static assets
  
- **API**: Public and internal endpoints
  - Public API routes
  - Internal service routes
  
- **SUITES**: Modular applications
  - Identity suite (auth, credentials, graph)
  - Sports suite (leagues, teams, events)
  - Creator suite (content, publishing)
  - Finance suite (transactions, pricing)
  - Quantum suite (quantum computing)
  
  Each suite contains:
  - `api/` — backend endpoints
  - `ui/` — frontend components

### Copilot should generate:
- Kernel modules (scheduler, memory manager, IPC handlers)
- Runtime bootstrap logic
- Routing system and service registry
- Web shell server
- Suite APIs and UI components
- Authentication and authorization middleware

---

## 3. Substrate (Planetary Compute Layer)

Substrate models planetary-scale computation and physics simulation.

### Components:

- **CLASS-B**: Regional geometry, dynamics, simulations
  - Geometric primitives
  - Dynamics equations
  - Regional simulations
  
- **CLASS-C**: Planetary fields, flows, constraints
  - Field equations
  - Flow models
  - Constraint solvers
  
- **TOOLS**: Analyzers and visualizers
  - Analysis tools
  - Visualization utilities

### Copilot should generate:
- Field equations and models
- Flow dynamics implementations
- Constraint solver logic
- Simulation scaffolding
- Analysis and visualization tools

---

## 4. Governance Layer

Umbrella governance defines the rules, identity, economics, and compliance of the system.

### Components:

- **IDENTITY**: Graph and credentials
  - Identity graph database
  - Credential management
  - Trust verification
  
- **POLICY**: Language and compilers
  - Policy language definitions
  - Policy compiler logic
  - Policy execution engine
  
- **ECONOMICS**: Pricing engines and token models
  - Pricing logic
  - Token distribution
  - Economic models
  
- **COMPLIANCE**: Logging and reporting
  - Audit logging
  - Compliance reports
  - Policy enforcement

### Copilot should generate:
- Identity APIs and graph operations
- Policy compiler scaffolding
- Pricing engines and models
- Compliance and audit modules
- Token and economic models

---

## 5. Infra

Infrastructure provides deployment, monitoring, and development tooling.

### Components:

- **DEV_SERVER**: Local development server
  - Hot reloading
  - Mock services
  - Dev logging
  
- **DEPLOYMENT**: Production deployment scripts
  - Container orchestration
  - Service deployment
  - Database migrations
  
- **CI_CD**: Continuous integration and deployment
  - Build pipelines
  - Test automation
  - Release workflows
  
- **MONITORING**: Observability and alerting
  - Metrics collection
  - Log aggregation
  - Health checks

### Copilot should generate:
- Dev server scripts and configs
- Deployment scaffolding (Docker, K8s)
- CI/CD pipeline definitions
- Monitoring and alerting hooks
- Infrastructure-as-code templates

---

## Overall Intent

Copilot should treat this repository as a **full operating system** with:
1. A cognitive builder engine (SIM)
2. A runtime kernel and services (Portal-OS)
3. Modular applications (Suites)
4. Planetary-scale compute substrate
5. Governance and compliance layer
6. Infrastructure for deployment and monitoring

**All generated code should:**
- Follow the folder structure exactly
- Use the naming conventions defined in this repo
- Maintain loose coupling between modules
- Respect module boundaries and responsibilities
- Generate complete, production-ready implementations
- Include tests, documentation, and configuration
